## Hi! 
This is pyPokédex, a Python CLI Pokédex. It's designed for me to get my feet a bit wet with RESTful APIs. 
This Pokédex utilizes the **PokéAPI** to grab all Pokémon data. 

In the future, I think it would be cool to expand this concept further into a full-on application with, of course, a catchier name. Stay tuned! 

Until then, I'll outline some features and whatnot that I think would be cool to add, for future reference.

## Goals: 
- Include Pokémon Weaknesses and Strengths.
- Include Pokémon descriptions.
- Include Pokémon Generation.
- Conversion to an application interface, complete with visuals of the Pokémon's sprites and sounds.
